Problema A — Apartamentos Límite: 1.0s / 512 MB
Hay n solicitantes y m apartamentos gratuitos. Tu tarea es distribuir los apartamentos de manera que el mayor
número posible de solicitantes consiga uno.
Cada solicitante tiene en mente un tamaño de apartamento deseado, y aceptará cualquier apartamento cuyo
tamaño sea lo suficientemente aproximado al tamaño deseado.
ENTRADA
La primera línea de entrada contiene tres números enteros n, m y k: el número de solicitantes, el número de
apartamentos y la diferencia máxima permitida.
La siguiente línea contiene n números enteros a1, a2, ..., an: el tamaño deseado por cada solicitante.
La última línea contiene m números enteros b1, b2, ..., bm: el tamaño de cada apartamento.
SALIDA
Imprime un número entero: la cantidad de solicitantes que obtendrán un apartamento.
RESTRICCIONES
1 ≤ n, m ≤ 2 · 10^5; 0 ≤ k ≤ 10^9; 1 ≤ ai, bi ≤ 10^9.
ENTRADA DE EJEMPLO
4 3 5
60 45 80 60
30 60 75
SALIDA DE EJEMPLO
2

Problema B — Combinaciones de Monedas II Límite: 1.0s / 512 MB
Consideremos un sistema monetario que consta de n monedas. Cada moneda tiene un valor entero positivo. Tu
tarea es calcular el número de formas ordenadas en las que puedes producir una suma de dinero x utilizando las
monedas disponibles.
Por ejemplo, si las monedas son {2, 3, 5} y la suma deseada es 9, hay 3 maneras: 2+2+5, 3+3+3 y 2+2+2+3.
ENTRADA
La primera línea contiene n y x. La segunda contiene n valores distintos de moneda.
SALIDA
El número de maneras módulo 10^9+7.
RESTRICCIONES
1 ≤ n ≤ 100; 1 ≤ x ≤ 10^6; 1 ≤ ci ≤ 10^6.
ENTRADA DE EJEMPLO
3 9
2 3 5
SALIDA DE EJEMPLO
3

Problema C — Asignación de Habitaciones Límite: 1.0s / 512 MB
Un hotel recibirá n clientes. Se conoce llegada y salida. Dos clientes pueden usar la misma habitación solo si la salida del primero es estrictamente anterior a la llegada del segundo. Calcula el número mínimo de habitaciones y una asignación válida.
ENTRADA
Un entero n seguido de n pares a,b de llegada y salida.
SALIDA
El mínimo k y una línea con el número de habitación de cada cliente en orden de entrada. Cualquier solución válida sirve.
RESTRICCIONES
1 ≤ n ≤ 2 · 10^5; 1 ≤ a ≤ b ≤ 10^9.
ENTRADA DE EJEMPLO
3
1 2
2 4
4 4
SALIDA DE EJEMPLO
2
1 2 1
